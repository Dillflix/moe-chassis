# Earlier illustrated instructions

These PDFs are preserved for their construction illustrations. **Use the [current assembly guide](../assembly.md) for the build sequence and current fit notes.**

- [Chassis assembly PDF](MOE_Chassis_Assembly_Guide.pdf): four-rod build and recessed connector details. It predates the PSU screw-seat report and the completed lid instructions.
- [Duct assembly PDF](MOE_Duct_Assembly_Guide.pdf): original adjustable cradles and tall carrier. Its carrier assembly and M3×55/M3×80 bolt selections are superseded for the Step 22 bar.
- [Original Step 20 duct notes](Ducts_Step20_README.md): retained design record, not the current installation route.

The [current duct guide](../duct-assembly.md) explains the low bar and changed bolt stack. The [current lid guide](../lid.md) replaces the older “future lid” notes.

For current source setup and STL generation, use [the build guide](../development.md); old archive paths and script names are historical.
